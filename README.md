# Loan Default Prediction

## Overview
This project applies supervised machine learning techniques to predict loan defaulting. By analyzing financial data, we identify key risk factors that contribute to default, helping lenders make data-driven decisions.

## Key Insights
- **Risk Assessment:** Identifies factors most correlated with loan default.
- **Supervised Learning Models:** Implements classification algorithms to predict default likelihood.
- **Feature Engineering:** Explores numerical and categorical variables to enhance model performance.

## Dataset
The dataset is sourced from **Kaggle**, containing loan information, borrower details, and default status.

## Technologies Used
- **Python** for data analysis and machine learning
- **Pandas & NumPy** for data manipulation
- **Matplotlib & Seaborn** for data visualization
- **Scikit-learn** for model implementation
